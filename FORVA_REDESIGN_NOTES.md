# FORVA PropTech frontend redesign package

Implemented in this source package:
- Bright, premium FORVA header and hero using the supplied hero video.
- Canonical FORVA logo and app icon assets.
- Nine alternating homepage feature showcases with contextual product-style visuals.
- Each feature has a working contextual “Learn more” route at `/features/:slug`.
- “How FORVA Works” two-row infinite carousel; top and bottom move in opposite directions and include AI Voice Conversation in the workflow.
- 10-slide customer story carousel with working arrows/dots/autoplay. Current entries are explicitly preview placeholders and must be replaced with verified customer testimonials before production.
- Light, structured FORVA footer with working internal navigation and legal links.
- Existing Supabase/auth/app/admin logic and routes were preserved; only public marketing UI/routing additions were made.

Important: testimonial copy is intentionally non-factual placeholder content. Do not publish it as customer endorsement.
